# Awesome Mystoq [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of [Mystoq](https://mystoq.com) resources, SDKs, themes,
> integrations, and community projects.

Mystoq is the simplest way to launch a cash-on-delivery online store
in Algeria & MENA - 58 wilayas, Yalidine/Maystro/Stop Desk integrated,
WhatsApp Commerce, FakeShield AI fraud detection. Free tier available.

## Official SDKs

- [mystoq-js-sdk](https://github.com/hartemyaakoub/mystoq-js-sdk) - JavaScript / TypeScript
- [mystoq-php-sdk](https://github.com/hartemyaakoub/mystoq-php-sdk) - PHP 8.1+
- [mystoq-python-sdk](https://github.com/hartemyaakoub/mystoq-python-sdk) - Python 3.9+
- [mystoq-openapi](https://github.com/hartemyaakoub/mystoq-openapi) - OpenAPI 3.1 spec (generate clients in any language)
